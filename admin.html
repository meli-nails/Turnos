Configuración inicial

Pasos necesarios para publicar el panel.

01 · Crear el proyecto

Proyecto conectado: vfkalbukfiyprugqepcy. Se utiliza la clave publishable pública.

02 · Ejecutar el esquema

El proyecto ya tiene su esquema productivo. No ejecutes un esquema alternativo ni crees tablas meli_* duplicadas.

03 · Autorizar al administrador

Creá el usuario en Authentication → Users y luego el usuario debe tener una fila en admins asociada por user_id.

04 · Compartir configuración

Completá supabase-config.js y publicá todos los archivos en el mismo origen/carpeta.
